# Security policy

Supported release line: 0.1.x. Report vulnerabilities through this repository's
GitHub Security → Report a vulnerability page. Do not post credentials or memory
contents in public issues. Include a minimal reproduction and affected versions.

ThothMemory is a loopback-only, shared-owner local service. It is not intended for
public hosting. See [the threat model](docs/SECURITY.md), including the limits of
agent identity, evidence attestation and stored-content prompt injection controls.
